# Definition of done for features

A feature is done when all six are true. Not before.

- [ ] **Metric tracked**: the success metric is live on a dashboard the team actually opens.
- [ ] **All states live**: empty, loading and error states are built, not just the happy path.
- [ ] **Teams briefed**: support and sales know what changed and how to explain it.
- [ ] **Can switch off**: there is a feature flag and a tested rollback.
- [ ] **Users can learn it**: a help article or in-app hint exists.
- [ ] **Review booked**: a post-launch review has a date and an owner.
