Chat or button? A decision guide

Ask these in order.

  1. Is the task the same every time? → Make it a button. Example: "Summarise this ticket", "Draft a reply".
  2. Does the user already know what they want? → Use a form or fields that AI fills in, and let the user edit. People edit faster than they prompt.
  3. Is the question open-ended or exploratory? → Now chat earns its place. Example: "Why did churn rise last month?"

Signs you picked the wrong one

  • Users type the same request again and again → it should be a button.
  • Users don't know what to ask → add suggested actions or a form.
  • A button gives answers people constantly rewrite → let them guide it with a short prompt.

Good combinations

  • Buttons for the common actions, chat for everything else.
  • A button that opens a pre-filled prompt the user can edit.
