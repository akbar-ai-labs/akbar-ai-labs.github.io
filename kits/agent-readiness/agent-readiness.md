# Agent readiness checklist

Before an AI agent can **act** (not just answer), you should be able to answer all eight.

1. **Identity**: does the agent have its own identity, separate from any person?
2. **Permissions**: does it have only the access its job needs, and no more?
3. **Allowed actions**: is there a written list of the actions it may take?
4. **Approvals**: which actions need a person to approve first, and who approves?
5. **Audit trail**: is every action logged with what, when, why and which rule allowed it?
6. **Off switch**: can someone stop it immediately, and undo what it did?
7. **Cost**: do you know what each run costs, and is there a monthly limit?
8. **Results**: how will you measure what it actually delivered?

If you can't answer one of these, the agent isn't ready to act. It can still help by suggesting, with a person doing.
